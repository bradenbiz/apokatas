# apokatas

Apokatas is a proposed open-source monetary system intended to make gold and silver usable as money, with other metals potentially considered later.

The project is in early discovery. The product, monetary guarantees, operating structure, providers, and implementation have not been selected. There is no application code or live service yet.

## Planning workflow

We are using Matt Pocock's [Wayfinder](https://github.com/mattpocock/skills/tree/main/skills/engineering/wayfinder) to clarify the project through decision questions. [GitHub Issues](https://github.com/bradenbiz/apokatas/issues) is the chosen tracker for the eventual map and its child issues. The first map has not been created because its destination still needs to be agreed.

Markdown files preserve the project brief, history, and context between sessions. Once decision issues exist, their resolution comments will hold the detailed decisions, with links from the map and these records as needed.

See [AGENTS.md](AGENTS.md) for continuity instructions and [issue tracker conventions](docs/agents/issue-tracker.md) for the GitHub workflow.
